# স্মার্ট ব্ল্যাকবোর্ড ও PDF টিচিং স্টুডিও

কোচিং সেন্টারের জন্য ওয়েব অ্যাপ — PC, ট্যাবলেট ও মোবাইলে চলে, ইন্টারনেট ছাড়াও (একবার খোলার পর) কাজ করে।
কোনো সার্ভার, ডাটাবেস বা অ্যাকাউন্ট লাগে না। সব তথ্য ব্রাউজারের ভেতরে (IndexedDB) সেভ হয়।

## ফিচার
- কালো/সাদা বোর্ড: কলম, হাইলাইটার, ইরেজার, আকৃতি, লেখা, আনডু/রিডু, জুম, প্যান
- নোটবুক ও পাতা ব্যবস্থাপনা: টেমপ্লেট, পাতা কপি/মোছা/সরানো
- PDF ইমপোর্ট ও মার্কআপ, ছবি ইমপোর্ট, PDF ও PNG এক্সপোর্ট
- OCR (বাংলা + ইংরেজি) — স্ক্যান করা পাতা থেকে লেখা শনাক্ত
- প্রেজেন্টেশন মোড (লেজার পয়েন্টার সহ)
- JSON ব্যাকআপ ও রিস্টোর — ডেটা হারানোর ঝুঁকি কমাতে নিয়মিত ব্যাকআপ নিন
- অটোসেভ, অফলাইন মোড (PWA — ফোনে "Add to Home screen")

## অনলাইনে প্রকাশ (HTTPS জরুরি — Service Worker ও ইনস্টলের জন্য)
এই ফোল্ডারটি যেকোনো স্ট্যাটিক হোস্টে আপলোড করলেই চলবে:

1. **Netlify**: app.netlify.com/drop-এ পুরো ফোল্ডার টেনে আনুন। (netlify.toml ও _headers স্বয়ংক্রিয়ভাবে কাজ করবে)
2. **Cloudflare Pages**: নতুন Pages প্রজেক্ট → "Direct upload" → ফোল্ডার আপলোড।
3. **GitHub Pages**: নতুন repo-তে ফাইলগুলো push করে Settings → Pages → Deploy from branch।
4. **Vercel**: vercel.json সহ ফোল্ডার import করুন।

নিজের ডোমেইন (যেমন `board.yourcoaching.com`) যুক্ত করতে হোস্টের "Custom domain" মেনু ব্যবহার করুন।

## পিসিতে পরীক্ষা
```
python3 -m http.server 8000
```
তারপর ব্রাউজারে http://localhost:8000 খুলুন। index.html সরাসরি ফাইল হিসেবে খুললে PDF ও অফলাইন ফিচার কাজ করবে না।

## আপডেট দেওয়ার নিয়ম
নতুন ভার্সন প্রকাশের সময় `sw.js`-এর `VER` (যেমন `sb-v2` → `sb-v3`) বাড়ান। এতে ব্যবহারকারীদের ক্যাশ নতুন হয়ে যাবে।

## ফোল্ডারের কাঠামো
```
index.html            মূল পেজ
css/style.css         স্টাইল
js/                   util, db (IndexedDB), render, app, ui
sw.js                 অফলাইন সার্ভিস ওয়ার্কার
manifest.webmanifest PWA ইনস্টল তথ্য
vendor/               PDF.js, pdf-lib, Tesseract OCR (অফলাইনে চালানোর জন্য)
fonts/                Noto Sans Bengali
icons/                অ্যাপ আইকন
_headers, netlify.toml, vercel.json   হোস্টিং ও নিরাপত্তা হেডার
```

## ব্রাউজার সাপোর্ট
Chrome, Edge, Safari (iOS 16.4+), Firefox — সর্বশেষ সংস্করণ। স্ক্রিন বড় হলে PC/ট্যাবলেটে সবচেয়ে ভালো অভিজ্ঞতা।

## সীমাবদ্ধতা (গুরুত্বপূর্ণ)
- এটি একক-ডিভাইস টিচিং টুল। একাধিক শিক্ষক/শিক্ষার্থী রিয়েল-টাইমে একই বোর্ডে যুক্ত হওয়া (লগইন, লাইভ ক্লাস, ভিডিও, হাত-তোলা অনুমতি) এই সংস্করণে নেই।
- ডেটা ব্রাউজারে থাকে। ব্রাউজারের ডেটা মুছে গেলে বা ডিভাইস বদলালে JSON ব্যাকআপ থেকে রিস্টোর করুন।
